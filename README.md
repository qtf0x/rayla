A ray tracing library and application framework.

Rayla provides types and routines for sythesizing images of 3D scenes via the
[ray tracing](https://en.wikipedia.org/wiki/Ray_tracing_(graphics)) algorithm.
It serves mainly as an educational project; the algorithms, architecture, and
techniques used should be assumed neither optimal nor idiomatic.
