# rayla

Rayla is a ray tracing library and 3D renderer written in C. She's also very shy - don't be afraid to say hello! <3

Build system generator by CMake: https://cmake.org/

Formatting by clang-format: https://clang.llvm.org/docs/ClangFormat.html

Tests by gtest: https://github.com/google/googletest

Originally based on the book "The Ray Tracer Challenge" by Jamis Buck: http://www.jamis.jamisbuck.org/
